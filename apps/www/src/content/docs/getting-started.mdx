## Installation

Download the latest release for your platform from
[GitHub Releases](https://github.com/vladimir-e/capybudget/releases).

### macOS

Open the `.dmg` file and drag Capy Budget to your Applications folder.

### Windows & Linux

Windows (`.msi`) and Linux (`.deb`) builds are coming soon via Tauri cross-compilation.

## Create a Budget

1. Launch Capy Budget.
2. Click **New Budget** and pick a folder. This is where your CSV files will live.
3. Create your first account (checking, savings, credit card, etc.).
4. Start adding transactions.

That's it. Your data is plain CSV files in the folder you chose.

## Sync Across Devices

Point your budget folder at a cloud sync service — iCloud Drive, Dropbox, Google Drive, or any folder sync tool. Capy Budget will pick up changes automatically.

## AI Features (Optional)

Smart import, auto-categorization, and natural language insights are powered by [Claude Code](https://claude.ai/code). Install the Claude CLI to unlock these features. The app is fully functional without them.

## Try the Demo

Not ready to install? [Try the web demo](https://demo.capybudget.app) — it runs entirely in your browser with sample data.
